## 速览

- **是什么**：两只手持夹爪（左、右）加一台 Meta Quest 3，用于录制双手操作演示
- **为什么**：用真机采集数据又慢又贵；手持夹爪让人在任何地方都能录制演示，数据可直接迁移到装有同款夹爪的机器人上
- **亮点**：Quest 手柄位姿追踪 · 每只夹爪两路腕部相机、H.264 硬件编码 · 通过 ArUco 标记读取夹爪开合 · BLE 按键驱动头显上的状态机 · 每条演示结束后 Wi-Fi 自动上传

## 要解决的问题

**UMI**（Universal Manipulation Interface）的思路很简单：给人一个与机器人夹爪一致的手持工具，记录人的操作，再用这些记录训练机器人。难点在工程上，每条录制都需要：

- 每只夹爪的**位姿**，精度要足以在机械臂上复现
- **夹爪视角的视频**，也就是机器人腕部相机将来看到的画面
- 每一时刻夹爪**张开了多少**
- 以上数据全部**时间同步**、带标注，并且无需人工拷贝就能从设备上传走

双手任务意味着这一切翻倍：两只夹爪，外加操作员头部的第一视角画面。

## 演示

顶部视频展示了整套设备的实际使用：左侧是戴着 Quest 3（顶部装有双目相机）、手持夹爪的操作员，右侧是实时的腕部相机画面。每只夹爪的画面都能看到自己的手指和橙色指尖，与机器人腕部相机的视角一致。

每只夹爪都是一台独立的无线录制设备：

- **计算：树莓派 4**，使用其 **H.264 硬件编码器**录制两路相机，两路视频流不会占满 CPU。
- **相机：两个 USB 连接的 UVC 相机**，分辨率 640×480，安装在腕部，沿手指方向拍摄工作区域。
- **视觉读取夹爪状态**：手指上没有任何传感器或走线，而是贴有 **ArUco 标记**；腕部相机能看到标记，后处理时据此计算开合程度。
- **位姿：顶部刚性安装一只 Meta Quest 手柄**，手柄到夹爪的变换直接取自 CAD 模型，无需额外标定。
- **操作：手柄上的薄膜键盘**，用于开始、结束与标注，操作员全程无需放下夹爪。
- **供电：3S 电池**，整机不连接电脑或电源插座的线缆。

两只夹爪完全相同，左右手各一只。

每条演示由**三台设备同时录制**：

| 录制设备 | 录制内容 |
| --- | --- |
| Meta Quest 3 | 头部位姿、两只手柄的位姿（即夹爪位姿）、头部双目相机 |
| 左侧 UMI 设备 | 两路腕部相机（同时拍到左夹爪状态） |
| 右侧 UMI 设备 | 两路腕部相机（同时拍到右夹爪状态） |

### 状态机运行在头显上

整个采集流程由 **Quest 应用中的状态机**统一调度：

```
空闲 ──开始──▶ 录制中 ──结束──▶ 复核 ──标注──▶ 上传中 ──▶ 空闲
                                   │
                         成功 / 失败 / 丢弃
```

1. 操作员按下夹爪上**薄膜键盘**的按键。键盘连接树莓派，由树莓派通过 **BLE** 转发给 Quest。
2. **由 Quest 决定**下一个状态，并通过同一条 BLE 链路向**两台**树莓派下发**开始**或**结束**指令。
3. 结束后，操作员为这条演示**标注**成功、失败或丢弃。
4. 每台设备通过 **Wi-Fi** 把自己录制的部分**上传**到实验室服务器；在此之前，树莓派的视频保存在 microSD 卡上。

把状态机放在头显上，系统就有了**唯一的决策来源**：一次按键就是一个事件，Quest 做出一个决定，三台录制设备同步执行。两只夹爪不会在"是否在录制"上出现分歧。

### 多路数据同步

数据来自三个独立的时钟。树莓派通过网络（NTP）保持时钟同步，每个位姿和视频帧在采集时都打上**时间戳**，后处理时按最近时间戳对齐。

## 数据后处理

在实验室服务器上，每条带标注的演示被转换成训练数据：

- **对齐**：按时间戳对齐头显位姿、两只手柄位姿和所有相机帧
- **夹爪状态**：在每一帧腕部画面中检测 ArUco 标记，把标记间距换算为夹爪开合
- **夹爪位姿**：用 CAD 中的变换，把每只手柄的位姿换算到对应夹爪的指尖

最终得到同步的图像、夹爪位姿与夹爪状态，也就是机器人策略模型学习所需的观测与动作。

## 设计取舍

- **用 Quest 手柄定位，而不是视觉 SLAM**：原版 UMI（Chi 等，RSS 2024）在夹爪上安装 GoPro 录制，事后再从视频中恢复位姿。Quest 的 inside-out 追踪能实时给出每只夹爪的位姿，与头显处于同一坐标系，也不需要建图。
- **用标记读取夹爪状态，而不是传感器**：通过相机本就能看到的 ArUco 标记读取开合，运动的手指上不需要额外的电子元件和走线。
- **在树莓派上硬件编码**：每只夹爪两路相机，正是因为树莓派 4 的视频编码器承担了压缩才得以实现。
- **采用通用硬件**：Quest 3、树莓派 4、UVC 相机和 3D 打印件，整套设备成本低、易于复制。
