## 概要

两只手持夹爪加一台 Meta Quest 3，不用机器人就能录制双手操作演示。实验室服务器把每条标注过的演示转换成训练数据集，内含同步图像、夹爪位姿和夹爪开合。

每条录制都需要夹爪位姿、夹爪视角视频和夹爪开合，位姿精度要足以在机械臂上复现。双手任务让这些需求翻倍，还要加上操作员头部的第一视角画面。所有数据都要时间同步、带标注，而且不用人工拷贝就能从设备上取走。

每只夹爪顶部刚性固定一只 Quest 手柄，实时追踪夹爪位姿。每只夹爪上的树莓派 4 录制两路 640 × 480 腕部相机。视频由 H.264 硬件编码器压缩。手指上贴有 ArUco 标记，腕部相机拍到标记即可读出夹爪开合。

头显上的一个状态机调度全部三台录制设备：Quest 3 和两只夹爪。每次按键只产生一个事件，由 Quest 做一次决策。因此两只夹爪永远不会在“是否在录制”上出现分歧。标注完成后，各台设备通过 Wi-Fi 把自己录的那部分上传到实验室服务器。

用真机采集数据又慢又贵。按照 UMI（Universal Manipulation Interface）的思路，手持工具与机器人夹爪一致。在任何地方录下的演示，都能迁移到装有同款夹爪的机器人上。

## 设计优势

| 需求 | 本设备的做法 |
| --- | --- |
| 夹爪开合 | 手指上贴 ArUco 标记，由腕部相机读取，活动的手指里不需要传感器和走线 |
| 每只夹爪两路相机 | 压缩交给树莓派 4 的 H.264 硬件编码器，两路视频流才跑得动 |
| 手柄到夹爪的变换 | 直接取自 CAD 模型，无需标定 |
| 开始、结束和标注 | 握把上的薄膜键盘 |
| 数据转移 | 每条演示录完即通过 Wi-Fi 上传 |
| 供电 | 3S 电池 |

每只夹爪都是一台独立的无线录制设备，左右两只完全相同。电子部分都是现成部件（Quest 3、树莓派 4、UVC 相机），定制零件用 3D 打印。整套设备因此成本低，也容易复刻。

每个位姿和每帧视频在采集时都打上时间戳，后处理按最近时间戳匹配各路数据。

| 录制设备 | 录制内容 |
| --- | --- |
| Meta Quest 3 | 头部位姿、两只手柄的位姿（即夹爪位姿）、头部双目相机 |
| 左侧 UMI 设备 | 两路腕部相机（画面同时记录了左夹爪状态） |
| 右侧 UMI 设备 | 两路腕部相机（画面同时记录了右夹爪状态） |

<details>
<summary>状态机与时钟同步</summary>

```
空闲 ──开始──▶ 录制中 ──结束──▶ 复核 ──标注──▶ 上传中 ──▶ 空闲
                                   │
                         成功 / 失败 / 丢弃
```

1. 操作员按下夹爪上薄膜键盘的按键。键盘接在树莓派上，由树莓派通过 **BLE** 转发给 Quest。
2. Quest 决定下一个状态。随后通过同一条 BLE 链路，向**两台**树莓派下发**开始**或**结束**指令。
3. 停止录制后，操作员把这条演示标注为成功、失败或丢弃。
4. 各台设备通过 **Wi-Fi** 把自己录的那部分上传到实验室服务器。上传之前，视频保存在树莓派的 microSD 卡上。

各路数据来自三个独立的时钟。树莓派通过网络（NTP）保持时钟同步。

</details>

<details>
<summary>后处理步骤</summary>

- 按时间戳对齐头显位姿、两只手柄的位姿和所有相机帧。
- 在每帧腕部画面中检测 ArUco 标记，把标记间距换算成夹爪开合（即夹爪状态）。
- 用 CAD 模型中的变换，把每只手柄的位姿换算到对应夹爪的指尖，得到夹爪位姿。

这些同步的图像、夹爪位姿和夹爪状态，就是机器人策略学习所需的观测和动作。

</details>

## 与原版 UMI 对比

| 对比项 | 原版 UMI（Chi 等，RSS 2024） | 本设备 |
| --- | --- | --- |
| 位姿来源 | 对夹爪上 GoPro 的视频做视觉 SLAM | 对夹爪上的 Quest 手柄做 inside-out 追踪 |
| 位姿何时可用 | 录制结束后从视频中恢复 | 录制时实时给出，无需建图 |

两种设计都用手持夹爪上的相机录制，区别在于如何获得夹爪位姿。Quest 追踪还让两只夹爪的位姿和头显处在同一坐标系。
