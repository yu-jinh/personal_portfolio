# Glossary

Terms used across this portfolio site. Chinese is the primary language; each entry gives the English counterpart used in the English version of the site.

## Teleoperation / 遥操

Controlling a robot remotely in real time through an input device (e.g. a VR headset), where the robot mirrors the operator's motions.

## Data Collection / 数据采集

Recording robot sensor streams and operator demonstrations into datasets used for training robot policies. A dataset entry pairs observations (images, proprioception) with the actions the operator took.

## UMI Data Collection / UMI 数据采集

One of the portfolio projects: a self-built handheld capture device (Raspberry Pi 4 based) that records demonstrations wirelessly and uploads them to the dataset hub automatically.

## EGO Data Collection / EGO 数采

One of the portfolio projects: a data collection setup using a Meta Quest 3 (hand tracking) plus an external USB stereo camera, covering recording, encoding, and upload.

## Interactive Control / 交互控制

Portfolio grouping for projects where a human drives a device in real time (teleoperation, conversational control), as opposed to data collection projects that produce training datasets.

## Embodied AI / 具身智能

The target job direction this portfolio serves: AI agents that perceive and act in the physical world through robot bodies. The site narrative is "collects data and builds interactive execution", the two halves of the embodied-AI loop.
